# LiveX game translate — downloads

Public downloads for LiveX, the live game subtitle translator: phone, computer and TV apps.

- Download page: https://redevrx.github.io/livex-game-translate/
- Files: [Releases](https://github.com/redevrx/livex-game-translate/releases)
- `tv/manifest.json` (+ `.sig`): the signed list of TV app packages the LiveX app installs onto a TV on the same Wi-Fi.

This repository holds no source code.
